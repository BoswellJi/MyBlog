openGL历史

  1. SGI为工作站专门设计了3D图形api,IRIS GL API;
  2. 增加较多功能，所以需要实现向后兼容；
  3. IRIS GL api后来变得越来越难以维护，也越来越难使用；
  4. 所以这时候，需要开发一个开放的标准；
  5. 标准使得程序员比较容易建立与他们的图形硬件相兼容的软件；
  6. SGI公司开始从头设计openGL；
  7. openGL结构评审委员会决定openGL未来（openGL ARB）
  8. openGL ARB 转交给 Khronos小组（同时该组织也负责webgl规范
  9. openGL的升级策略，总是保证新版本的向后兼容
  10. 带有可编程着色器的openGL与webGL十分相似

openGL es

  1. webgl的蓝本是opengl es 2.0
  2. opengl es 2.0无法与以前的版本实现向后兼容

Direct3D

  1. DirectX是微软多媒体和游戏编程api的名称
  2. Reality Lab 3D 图形 api
  3. 微软利用上面的技术开发了Direct3D的第一个版本
  4. 造成台式3D图形的分崩离析，但同时也造成3D图形行业的健康竞争
  5. openGL Direct3D
  6. Direct3D第八版本，加入可编程着色器
  7. 第九版推出 高级着色器语言HLSL

HTML5画布

  1. html的第5版本;
  2. canvas是web页面中的一个矩形区域，在这个区域我们可以用 javascript 语言编写 绘制图形 的代码；
  3. Dashboard是包含许多小部件Widgets的小型应用程序，这些 小部件 与 web页面 一样，都是建立在 html,css，javascript 等技术之上的；
  4. Dashboard和safari web浏览器一样，都是使用webkit开源浏览器引擎绘制web内容；

可缩放矢量图形

  1. 一个用xml格式描述2D图形的语言；
  2. 使用点，线，曲线等集合图元，把这些几何图元保存为数学表达式；
  3. 显示矢量图形的程序，根据这些数学表达式生成屏幕上的图像；
  4. 这样会使，用户放大图形，svg生成的图像保持一样的清晰度；
  5. 微软等公司以建议标准的形式向w3c提供了矢量标志语言（VML）；
  6. adobe等公司提出另一个建议标准,精密图形标志语言（PGML）;
  7. w3c从两种建议标准各取一部分，组成svg(SVG)，2001年称为w3c的推荐标准；
  8. svg包含svg(svg Tiny)微型版【针对低端移动设备】，svg(svg Basic)基础版【针对高端移动设备】
  9. 基于文本的

VRML和X3D

  1. VRML: 用于描述3D图形的，基于xml的虚拟显示标志语言
  2. X3D： 是VRML的后继者
